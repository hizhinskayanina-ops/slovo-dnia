# Слово дня

Одне англійське слово чи фраза щодня з українським перекладом, прикладом, озвучкою й повторенням за інтервалами (1 → 3 → 7 → 14 → 30 → 60 днів).

- Застосунок (PWA): https://hizhinskayanina-ops.github.io/slovo-dnia/
- Список слів: `words.json` (поля: en, uk, ex, ex_uk, tag). Додати слово = додати рядок із новим id.
- Віджет на екран iPhone: `widget-scriptable.js` для застосунку Scriptable. Показує слово дня й ставить нагадування о 8:00.
- Прогрес повторень лежить лише в телефоні (localStorage), на сервер нічого не йде.

Джерело: `Клод\Іві\slovo-dnia\` в OneDrive. Публікація: репозиторій `hizhinskayanina-ops/slovo-dnia`, гілка main, GitHub Pages.
