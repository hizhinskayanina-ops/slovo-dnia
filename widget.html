Віджет «Слово дня» на екран iPhone

  1. Постав безплатний застосунок Scriptable з App Store.
  2. Натисни кнопку нижче, код скопіюється.
  3. Відкрий Scriptable → «+» угорі праворуч → утримай палець у порожньому полі → Вставити.
  4. Натисни назву «Untitled Script» угорі → перейменуй на Слово дня → Done.
  5. На домашньому екрані утримай палець на порожньому місці → «+» угорі ліворуч → знайди Scriptable → середній розмір → Додати.
  6. Натисни на новий віджет → Script → обери Слово дня. Готово. Дозволь сповіщення, коли запитає.
